# What to Learn Before Agents / Tool Calling

Before starting the Agents / Tool Calling interview questions, make sure you understand the following concepts.

## 1. LLM Basics

You should understand:

- What is an LLM?
- How an LLM generates a response
- Tokens
- Context window
- Prompts
- System, user, and assistant messages
- Temperature and basic generation settings
- Hallucination

The important idea is:

```text
User Input
    ↓
Prompt
    ↓
LLM
    ↓
Generated Response
```

An agent builds on this basic LLM interaction.

---

## 2. Basic Python

You should be comfortable with:

- Variables
- Functions
- Classes and objects
- Lists and dictionaries
- Loops and conditions
- Exception handling
- JSON
- Basic file handling

Tool calling commonly involves defining functions that an agent can invoke.

Example:

```python
def get_weather(city):
    # Call weather API
    return weather_data
```

The LLM can decide that this function is needed, while the application actually executes it.

---

## 3. Functions and APIs

Understand:

- What is a function?
- Function parameters
- Return values
- REST APIs
- HTTP requests
- GET / POST
- JSON request and response
- API authentication at a basic level

A tool is often simply an application function that connects to an external system.

```text
Agent
  ↓
Tool
  ↓
API / Database / Service
  ↓
Tool Result
  ↓
Agent
```

---

## 4. Structured Data and JSON

Tool calling heavily depends on structured inputs and outputs.

You should understand JSON objects such as:

```json
{
  "city": "Delhi",
  "units": "celsius"
}
```

Also understand:

- Keys and values
- Nested objects
- Arrays
- Data types
- Basic JSON validation

This becomes important when an LLM generates arguments for a tool.

---

## 5. LLM Tool Calling Basics

Before learning full agents, understand this basic flow:

```text
User
 ↓
LLM
 ↓
Tool Selection
 ↓
Tool Arguments
 ↓
Application Executes Tool
 ↓
Tool Result
 ↓
LLM
 ↓
Final Answer
```

Important distinction:

> The LLM does not directly execute your Python function or API.

The application receives the tool call generated by the LLM, executes the tool, and sends the result back to the LLM.

---

## 6. Basic Database Concepts

You should understand:

- What is a database?
- Tables and records
- SQL queries
- CRUD operations
- Database connections
- Basic filtering

Agents can use databases as tools.

For example:

```text
User
 ↓
Agent
 ↓
Database Tool
 ↓
SQL Query
 ↓
Database
 ↓
Result
 ↓
Agent
```

You don't need advanced database internals before starting agents.

---

## 7. RAG Basics

Since agents can use RAG as a tool, you should understand:

- What is RAG?
- Embeddings
- Vector databases
- Retrieval
- Top-k
- Metadata filtering
- Reranking
- Context construction

Basic relationship:

```text
RAG Pipeline
     ↓
Can become a Tool
     ↓
Agent decides when to use it
```

For example:

```text
User Question
      ↓
Agent
   /      \
RAG Tool  Calculator
   ↓          ↓
Documents   Result
   \          /
      Agent
        ↓
   Final Answer
```

---

## 8. Workflow vs Agent

You should understand the basic difference.

### Workflow

The steps are mostly predefined.

```text
Step 1
  ↓
Step 2
  ↓
Step 3
  ↓
Final Result
```

### Agent

The next action can be selected dynamically.

```text
Goal
 ↓
LLM
 ↓
Choose Action
 ↓
Observe Result
 ↓
Choose Next Action
 ↓
...
```

This distinction is fundamental to understanding agentic systems.

---

## 9. State and Memory Basics

Understand the difference between:

- Current state
- Conversation history
- Short-term memory
- Long-term memory
- Persistent state

An agent may need to remember information across multiple tool calls.

For example:

```text
Step 1 → Search for flights
            ↓
Step 2 → Store selected flight
            ↓
Step 3 → Check availability
            ↓
Step 4 → Book flight
```

The agent needs state to keep track of information between these steps.

---

## 10. Basic Error Handling

Understand:

- Exceptions
- Timeouts
- Retries
- Validation
- Fallbacks
- Error messages

Tools can fail.

```text
Agent
 ↓
Tool
 ↓
ERROR
 ↓
Retry / Recover / Choose Another Action
```

Reliable agents must be able to handle tool failures instead of assuming every tool call succeeds.

---

## 11. Basic Security Concepts

Before learning production agents, understand:

- Authentication
- Authorization
- Access control
- Input validation
- Prompt injection
- Untrusted external data
- Sensitive information

An agent that can call tools can potentially perform real actions, so tool permissions must be controlled.

---


## Minimum Prerequisites

Before starting the interview questions, make sure you can explain:

```text
1. What is an LLM?
2. What is a Python function?
3. What is an API?
4. What is JSON?
5. What is RAG?
6. What is a database?
7. What is a workflow?
8. What is state?
```

You do **not** need to master LangChain or LangGraph before starting.

First understand the underlying concepts of:

```text
LLM
 ↓
Tool Calling
 ↓
Agent Loop
 ↓
State
 ↓
Multiple Tools
 ↓
Agent
```
