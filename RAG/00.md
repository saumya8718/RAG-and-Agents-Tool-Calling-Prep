# RAG — Retrieval-Augmented Generation

Retrieval-Augmented Generation (RAG) is an approach that combines
information retrieval with Large Language Models (LLMs).

Instead of relying only on the knowledge stored in an LLM, a RAG
system retrieves relevant information from an external knowledge
source and provides it to the LLM as context for generating an answer.

## Why Learn RAG?

RAG is commonly used when an LLM needs access to:

- Private or domain-specific information
- Frequently changing information
- Large document collections
- External knowledge bases
- Enterprise data

## Basic RAG Flow

User Query
     ↓
Query Processing
     ↓
Retrieval
     ↓
Relevant Documents / Chunks
     ↓
Context Construction
     ↓
LLM
     ↓
Generated Answer
